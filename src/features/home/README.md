# Home Feature

## Overview

The Home feature introduces visitors to GradFlowers, highlighting commencement collections, value propositions, and direct entry points to the flower catalog.

## Structure

- `pages/HomePage.tsx`: Route composition container.
- `components/HeroSection.tsx`: Headline, graduation badges, and quick CTA buttons.
- `components/FeaturesHighlight.tsx`: Key benefits such as commemorative ribbons and campus delivery.
